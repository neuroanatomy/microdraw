Embedding a MicroDraw dataset

This page embeds the test dataset /test_data/cat.json with the regions of the project embeddemo. To see it on a local server, create that project (/project/new), add the file /test_data/cat.json, and let anyone view its files and annotations. An embed only shows what an anonymous visitor may see: a framing site sends no session cookie.

The short way: one script tag

<script src="https://microdraw.pasteur.fr/embed.js"
        data-source="/test_data/cat.json"
        data-project="embeddemo"></script>

The script inserts an iframe where the tag sits, and keeps it at the height the viewer asks for. Its options are data-* attributes:

AttributeMeaning
data-sourceRequired. Source URL of the dataset
data-projectProject whose regions are shown; without it, the image alone, if a project listing it is public
data-sliceInitial slice number (the middle slice by default)
data-max-heightCap, in px, on the height the viewer asks for
data-microdraw-link0 hides the MicroDraw link
data-width, data-max-width, data-heightThe box: 100%, 560px and 420px by default (the height is a starting guess)
data-targetCSS selector of the element to render into

The explicit way: an iframe

<iframe src="https://microdraw.pasteur.fr/data/embed?source=%2Ftest_data%2Fcat.json&project=embeddemo&slice=0"
        style="width:100%; max-width:560px; height:420px; border:0"
        allow="fullscreen" allowfullscreen></iframe>

The query parameters are source, project, slice, maxHeight and microdrawLink; any other is ignored. The viewer is always read-only. allow="fullscreen" lets its full-screen button work.

Auto-sizing

The viewer posts {type: 'microdraw:embed-resize', height, width, aspect, slice} to its parent on load, on each slice change, and when its width or its toolbar changes. height is computed from the image's aspect ratio and the toolbar. A host page that writes the iframe itself listens for it (this one does, for the iframe above): 

window.addEventListener('message', function (event) {
    if (event.source !== iframe.contentWindow) { return; }
    if (!event.data || event.data.type !== 'microdraw:embed-resize') { return; }
    if (typeof event.data.height !== 'number' || event.data.height <= 0) { return; }
    iframe.style.height = event.data.height + 'px';
});
